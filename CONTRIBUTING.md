# Contributing

## Development

Node 24 or later.

```sh
npm ci
npm run typecheck
npm run verify        # the app on a free port, fake data, screenshots and a report
```

## How changes are made

1. **One issue, one PR.** Small issues labeled `agent` are picked by the builder routine.
2. **CI on every PR:** typecheck, secret scan and `npm run verify`, with screenshots in a PR comment.
3. **Review** by a separate reviewer (Codex) with a clean context; the PR merges when Codex passes and CI is green.
4. **Merge to `main` deploys** (D1 migrations, then `wrangler deploy`) and publishes a Release `pr-N`.

Decisions that change the design get an ADR in [`docs/adr/`](docs/adr/). Maps are generated by `docs/architecture/draw_flows.py`; never edit the PNGs by hand.
